# 项目范围与路线图

## 项目定位

SocialDatabase 是群成员历史数据的聚合、保存和检索工具。当前版本消费外部
产生的 xlsx，不负责自动获取群成员数据。

导入采用非破坏性合并：

- 新记录写入数据库。
- 新非空值更新最后已知资料。
- 空值不清除旧值。
- 新数据源缺少某个成员时不删除历史关系。

## 当前阶段

当前核心能力包括：

- 多工作表 xlsx 校验与导入。
- SQLite 规范化模型和事务 upsert。
- 数据源哈希、重复跳过和强制重处理。
- 导入批次、来源统计和关系观察记录。
- 按字段、多用户分页搜索，数据库统计和批次查询。
- JSON、CSV 和 xlsx 搜索结果导出。
- 数据库健康检查、一致性备份和恢复操作说明。
- Python 3.10、3.12、3.14 持续集成。

近期继续完善：

- 建立代表性数据规模的性能基线，按结果决定是否引入 SQLite FTS5。
- 演练备份恢复流程并定义稳定版发布检查清单。
- 确认其余 Excel 字段是否进入正式模型。
- 整理 AstrBot 现有数据输出与标准 xlsx 格式之间的适配约定。

## 稳定版本之后

稳定版本后考虑加入 HTTP 服务与 Docker 部署：

- 数据库和输入目录使用持久卷。
- 容器启动时检查 schema 版本。
- 提供搜索、统计、批次导入和健康检查 API。
- 与云服务器联动前加入认证、访问控制和 HTTPS。

## 远期数据获取

自动获取数据不属于当前核心范围。远期可以：

- 自建采集器并输出标准批次。
- 继续使用 AstrBot 插件生成 xlsx。
- 让 AstrBot 插件向未来 HTTP 服务提交标准 JSON。

采集器应作为外部适配器，核心合并和数据库逻辑不依赖 AstrBot。手动 xlsx
导入始终保留为独立后备方式。
