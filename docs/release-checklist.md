## 提交、标签与推送

1. 创建单一发布准备提交，并确认工作区干净。
2. 用户确认后创建带说明的 `vX.Y.Z` 标签。
3. 推送分支/提交和标签，确认远端 CI 全部通过。
4. 若托管平台需要 Release，再由该标签生成发布说明；不要提交本地构建产物。

标签和推送是外部状态变更，不包含在默认的本地发布检查中。
